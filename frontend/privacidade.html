Política de Privacidade

Versão inicial do produto — sujeita a atualização conforme o Movement evolui.

1. Sobre este documento

Este é um documento inicial, escrito em linguagem simples, para explicar quais dados o Movement usa e para quê. Ele descreve o que o sistema realmente faz hoje — não é uma peça jurídica completa, e será revisado conforme o produto crescer.

2. Quais dados o sistema utiliza

Para clientes: nome, email, telefone (opcional) e senha. Para funcionários e administradores, os mesmos dados básicos de conta. Também guardamos o histórico de pontos e de resgates associado à sua conta, porque é isso que faz o programa de fidelidade funcionar.

3. Para que esses dados são usados

Nome, email e telefone servem para identificar sua conta, permitir o login e para que um funcionário consiga te atender no balcão (conferir saldo, lançar pontos, validar um resgate). O histórico de pontos e resgates existe para calcular seu saldo e mostrar seu extrato — sem ele, o programa de pontos simplesmente não teria como funcionar.

4. Como sua senha é tratada

Sua senha nunca é guardada como texto — ela passa por um processo de hash (bcrypt) antes de ir para o banco de dados. Isso significa que nem mesmo um administrador do sistema consegue ver sua senha real; o sistema só consegue confirmar se a senha digitada bate com o hash guardado, nunca "ler" a senha original de volta.

5. QR Code pessoal e códigos de resgate

Seu QR Code pessoal (usado para o funcionário te identificar no balcão) é um identificador aleatório, sem nenhuma relação visível com seu nome, email ou qualquer outro dado pessoal — quem escaneia não lê seu nome, apenas um código interno que o sistema usa para localizar sua conta. O mesmo vale para o código gerado quando você resgata uma recompensa: ele identifica o resgate, não você.

6. Quem tem acesso aos seus dados

Funcionários e administradores do estabelecimento têm acesso apenas ao necessário para operar o programa — nome, telefone e saldo, por exemplo — para poder te atender. Ninguém além do próprio sistema tem acesso à sua senha, mesmo em forma de hash, fora do banco de dados.

7. Segurança

O sistema usa conexão criptografada (HTTPS), senhas protegidas por hash, limite de tentativas de login para dificultar tentativas automatizadas de acesso indevido, e outras medidas técnicas de proteção mantidas e revisadas continuamente.

8. Por quanto tempo os dados ficam guardados

Seus dados de conta ficam guardados enquanto sua conta existir. Recompensas ou resgates que deixam de estar disponíveis não são apagados — eles continuam no seu histórico, para que seu extrato de pontos permaneça completo e correto.

9. Contato

Este documento ainda não inclui um canal de contato dedicado para questões de privacidade, porque ele ainda não foi definido para o produto. Assim que existir, esta página será atualizada.
